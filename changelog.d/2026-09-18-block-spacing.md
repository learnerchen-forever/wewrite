Quotes, callouts, tables, code blocks, formulas, Mermaid diagrams and Excalidraw
frames can now be given a vertical rhythm from the theme (one value drives both
the top and the bottom margin, the same way image spacing already worked) —
so a dense technical note no longer depends on each block's built-in spacing.
A theme that sets nothing keeps the existing spacing.
