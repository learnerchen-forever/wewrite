The ten built-in themes and the ten downloadable themes were rebuilt on the same
theme system, so a built-in theme now dresses every element — headings, quotes,
callouts, tables, dividers, lists, inline marks, images, formulas, Mermaid and
Excalidraw — instead of only the handful the old built-in presets knew about.
The themes were rewritten to differ from each other in accent, background, type
and silhouette rather than in name only; the ten built-in ids are unchanged, so
a theme you already selected stays selected.
