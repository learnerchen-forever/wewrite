# 教程 2：主题与排版定制

> 让每一篇文章都穿上你喜欢的"衣服"。WeWrite 的主题就是一篇 Markdown 笔记——像写笔记一样设计排版。

---

## 目标

- 认识"主题 = Markdown 笔记"的机制
- 为文章选择/切换主题
- 创建一个自己的主题
- 逐项定制标题、代码块、表格等装饰

## 一、主题是什么

在 WeWrite 中，一个主题就是一篇带有 `wewrite_theme: true` 的 Markdown 笔记，通过 YAML frontmatter 里的样式变量描述整套排版（字体、颜色、间距、各元素装饰等）。

- 主题文件存放在你的 WeWrite 文件夹（默认 `wewrite/`）下的 **`themes/`** 子目录
- 插件启动时会自动扫描并出现在样式选择器里

## 二、为文章选择主题

1. 打开推文视图（右键 → 作为微信公众号推文）
2. 顶部工具栏的 **样式下拉框** 中选择主题
3. 右侧手机框实时预览

内置主题（可直接使用）：

| 主题 | 风格 |
|------|------|
| 简约 GitHub | 干净利落，代码感 |
| 经典微信 | 公众号最常见的排版 |
| 优雅衬线 | 衬线字体，适合文学/深度内容 |

> 💡 **下载更多模板**：设置 → 自定义主题 → **下载模板**，一键下载预建主题到 `themes/` 目录。

## 三、创建自己的主题

### 方式 A：主题向导（推荐新手）

1. 命令面板执行 **"New WeWrite Theme..."**
2. 按向导填写名称、配色等，自动生成主题笔记
3. 保存后主题立即出现在样式选择器中

### 方式 B：手写主题笔记

1. 在 `wewrite/themes/` 下新建 `我的主题.md`
2. 开头写入：

```markdown
---
wewrite_theme: true
wewrite_theme_name: "我的主题"
---
<!-- 在下方用 CSS 变量定义你的排版，或参考内置主题 -->
```

3. 修改后保存即生效（无需重启）

### 方式 C：主题编辑器

在文件管理器中对带 `wewrite_theme: true` 的笔记 **右键 → 编辑 WeWrite 主题**，打开可视化编辑器，左侧改 YAML、右侧实时预览。

> 🎨 **取色**：编辑器内所有颜色控件（主题色、色板、元素自定义颜色、框线颜色）点击后打开**全平台统一的取色对话框**（饱和度/明度方块 + 色相条，支持 RGB/HSL/HEX 三种输入模式），移动端与桌面端体验一致，不依赖系统原生取色器。
> 📱 **移动端显示**：编辑器的分组采用扁平化样式——去掉分组边框与内部元素边框，仅保留分组标题下方的分隔线；输入控件保持紧凑高度，触控友好的按钮不受影响。

## 四、逐项定制元素装饰

WeWrite 提供丰富的元素装饰系统（内置 100+ 项可选项），覆盖：

- **标题**：下划线、左边框、古典、纸媒、色块、渐变、卡片等
- **代码块**：12 种配色主题（One Dark / GitHub / Nord / Dracula…）、字号、内边距、Mac 红绿灯标题栏、行号、语言标签
- **引用 / Callout**：边框、底色、图标风格
- **表格**：表头风格（灰/主题色/渐变）、边框、斑马纹、字号
- **列表**：符号、编号样式、缩进、任务勾选图标
- **分割线**：实线/虚线/渐变
- **链接 / 加粗 / 行内代码**：颜色与下划线策略
- **数学公式 / Mermaid**：颜色与缩放

**在哪调**：在主题编辑器中找到对应元素的配置项（下拉/开关/滑块）修改即可；部分高阶玩法可通过「粘贴 HTML 自定义样式」为元素设置任意 CSS。

## 五、样式变量速查

主题笔记 frontmatter 中的核心变量（部分）：

| 变量 | 含义 |
|------|------|
| `accent` | 主强调色（标题/链接/按钮） |
| `accentDeep` | accent 的深色变体 |
| `background` | 页面背景色 |
| `fontFamily` / `fontSize` | 正文字体与字号 |
| `lineHeight` / `letterSpacing` | 行高与字距 |
| `margin` | 页边距 |
| `pageWidth` | 页面宽度（标准/宽屏/全宽） |

> 完整变量清单见主题编辑器内的提示与内置主题源码。

## 常见问题

| 问题 | 解决 |
|------|------|
| 新建主题后选择器里看不到 | 确认文件在 `wewrite/themes/` 下且 frontmatter 含 `wewrite_theme: true`；或重新打开设置页刷新 |
| 修改主题后预览没变化 | 点击推文视图顶部的 **刷新渲染** 按钮 |
| 想把某篇笔记固定用某主题 | 在笔记 frontmatter 中写 `wewrite_theme: true` 会把该笔记当作主题；普通笔记则在推文视图手动选择样式 |
| 微信里效果和预览不一致 | 以手机框预览为准；若仍有差异，检查是否使用了微信不支持的字符/元素 |
