# 教程 4：封面与图片

> 微信对封面比例有严格限制（横版 2.35:1）。WeWrite 用"三区封面编辑器"帮你轻松合成合规封面，并对正文图片做裁剪与压缩。

---

## 目标

- 学会使用三区封面编辑器（A 横版 + B 方形 → 合成）
- 用 AI 一键生成封面
- 裁剪正文图片（4:3 / 1:1）
- 了解图片上传与去重机制

## 一、三区封面编辑器

打开推文视图，封面区域包含三个分区：

| 分区 | 比例 | 用途 |
|------|------|------|
| A | 2.35:1（横版） | 微信列表页大图 |
| B | 1:1（方形） | 分享卡片 / 其他场景 |
| C | 合成结果 | 由 A+B 自动合成，最终发布用 |

### 基本操作

1. **加载图片**：点击分区 → 从仓库选择 / 从系统加载；也可直接拖拽图片到分区
2. **调整**：拖拽移动、双指缩放（移动端）或滚轮缩放，调到你满意的构图
3. **合成**：点击 **合成** 按钮，A+B 合并为 C
4. **发布**：C 分区就绪（显示 ✓）后即可发布

## 二、AI 生成封面

1. 点击封面分区上的 ✨ 按钮
2. 输入描述（如 *"春日樱花下的咖啡馆，暖色调"*）
3. 选择尺寸（会自动匹配当前文生图模型的合法尺寸）
4. 生成后图片自动放入该分区，可继续微调

> 需要先在设置中配置**文生图 AI 账号**（见 [教程 3](03-ai-writing-tools.md)）。

## 三、正文图片处理

### 裁剪

在笔记的图片上 **右键 → 裁剪 (4:3)** 或 **裁剪 (1:1)**：

1. 拖动裁切框选择区域
2. 确认后生成裁剪后的新图片并替换引用

### 尺寸与说明

- 右键图片 → **图片尺寸**：设置宽度、对齐方式（左/中/右）
- 右键图片 → **图片说明**：为图片添加说明文字（发布时显示在图片下方）

### 上传约束（微信硬限制）

| 类型 | 限制 |
|------|------|
| 图片 | ≤ 10MB（过大需压缩；WeWrite 会自动校验并提示） |
| 视频/音频 | 无法自动压缩，发布前需手动处理（发布校验会中止并提示） |

## 四、图片上传与指纹去重

- 发布时，正文图片、封面、SVG（图表/公式）会统一处理并上传到你的**微信素材库**
- **指纹去重**：每张图片有 FNV1a-64 内容指纹；重复发布时，已上传的图片自动跳过，只上传新增内容——重复发布省 90%+ 时间
- 文件改名/移动不影响匹配（按内容指纹，不按路径）

## 五、常见图片问题排查

| 问题 | 解决 |
|------|------|
| 封面显示「⚠ 需要上传」 | 该分区的图片尚未上传/合成，点击合成或重新加载 |
| 图片太大无法上传 | 用外部工具压缩到 10MB 内；或删除重放更小的图 |
| 微信里图片变形 | 检查图片尺寸设置中的宽高比；封面务必使用 C 分区合成结果 |
| 引用了仓库里不存在的图片 | 重新插入图片（注意路径/文件名大小写） |
| 想要清除上传缓存重新上传 | 设置 → 通用 → **清除指纹**（谨慎：会强制全部重传） |

## 常用技巧

- **批量配图**：用 [教程 3](03-ai-writing-tools.md) 的"生成图片"先出图，再拖入封面分区或正文。
- **手机端**：相册图片可直接拖放/选择，封面支持双指缩放，触控友好。
- **图片消息**：纯图推送场景（最多 20 张图 + 说明）用 NewsPic 视图，见 [教程 5](05-materials-and-newspic.md)。
