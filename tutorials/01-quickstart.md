# 教程 1：快速开始 — 从笔记到微信公众号草稿

> 适用版本：WeWrite 2.0.pre8（Obsidian ≥ 1.5.0，桌面 / iOS / Android 均可）

本教程带你把第一篇 Obsidian 笔记变成微信公众号草稿。全文约 5 分钟。

---

## 目标

- 配置好微信公众号账号
- 把一篇 Markdown 笔记渲染成公众号排版
- 推送到微信草稿箱，并在手机上最终确认

## 前置条件

- Obsidian 已安装 **WeWrite** 插件并启用（社区插件市场搜索 "WeWrite"）
- 一个微信公众号（订阅号/服务号均可），且你拥有其 **AppID / AppSecret**
- 已登录公众号后台（mp.weixin.qq.com），能访问「设置与开发 → 基本配置」

## 第一步：配置公众号账号

1. 打开 Obsidian **设置 → 第三方插件 → WeWrite → 设置**
2. 找到「微信公众号账号」区域，点击 **添加微信公众号账号**
3. 填写：
   - **名称**：任意，如 "我的公众号"
   - **AppID** / **AppSecret**：从公众号后台「设置与开发 → 基本配置」复制
4. 点击 **测试连接**，显示「连接成功」即通过
5. 点击 **设为启用**

> 💡 **关于 IP 白名单**：微信要求你的出口 IP 在公众号后台的 IP 白名单中。
> - 若提示 `IP 不在白名单中`：把提示的 IP 添加到公众号后台「IP 白名单」，或在 WeWrite 设置中勾选 **使用中心 Token 服务器**（免配置白名单）。

## 第二步：写一篇笔记

用 Obsidian 正常写 Markdown 即可，WeWrite 支持：

- 标题、粗体、斜体、列表、任务清单、表格、引用、Callout
- LaTeX 数学公式（`$$ ... $$`）、Mermaid 图表（` ```mermaid `）
- 本地图片、Obsidian 内链嵌入等

## 第三步：打开微信推文视图

在笔记编辑器中 **右键 → 「作为微信公众号推文」**（或在命令面板执行同名前命令）。

页面分为三部分：

| 区域 | 作用 |
|------|------|
| 顶部工具栏 | 选择主题样式、模拟手机屏幕、刷新渲染、复制 HTML、发布 |
| 参数面板 | 标题、作者、摘要（可 AI 生成）、封面设置、发布选项 |
| 手机框预览 | 实时预览发布到微信后的效果 |

## 第四步：填写文章信息

在参数面板中：

1. **标题**：必填（最长 64 字）
2. **作者**：选填（最长 16 字）
3. **摘要**：选填（最长 120 字）——可点击旁边的 ✨ 按钮让 AI 自动生成
4. **封面**：见 [教程 4：封面与图片](04-cover-and-images.md)

## 第五步：发布到草稿箱

1. 确认预览效果满意
2. 点击 **发布到草稿箱**
3. 等待图片上传与草稿创建完成

> ⚠️ WeWrite **只发布到草稿箱**，绝不会自动群发。最终发送永远由你在手机上确认。

## 第六步：手机确认发送

1. 手机安装「**公众号助手**」App，登录同一公众号
2. 打开 **草稿箱**，找到刚推送的文章
3. 预览、修改、然后点击 **群发** 或 **发布**

---

## 常用技巧

- **重新发布**：修改笔记后再次点击发布，已上传过的图片会自动跳过（指纹去重），速度快很多。
- **复制 HTML**：预览满意后，也可以点「复制」把带样式 HTML 直接粘贴到公众号编辑器。
- **图片消息**：纯图片+说明的推送，用「作为微信公众号图片消息」视图，见 [教程 5](05-materials-and-newspic.md)。
- **手机端**：手机 Obsidian 上右键 → 长按弹出菜单即可打开推文视图，全程可完成写作与发布。

## 常见问题

| 问题 | 解决 |
|------|------|
| 测试连接失败，提示 IP 不在白名单 | 将提示的 IP 加入公众号后台白名单，或启用「使用中心 Token 服务器」 |
| 提示「未配置 AI 文本账号」 | 是正常提示：AI 功能需要额外配置，见 [教程 3](03-ai-writing-tools.md)；不影响手动发布 |
| 图片上传失败 | 检查图片是否超过 10MB；视频/音频过大需手动压缩（WeWrite 会给出校验提示） |
| 草稿箱里找不到文章 | 确认发布时选择的账号是「启用」状态，且手机 App 登录的是同一公众号 |
