# 教程 5：素材管理与图片消息（NewsPic）

> 微信素材库的图片、图文草稿、图片草稿都可以在 Obsidian 里直接管理；纯图片推送用 NewsPic 视图搞定。

---

## 目标

- 在 Obsidian 中浏览/同步微信素材
- 删除、下载、复制 CDN 链接、设为封面
- 制作并发布一条"图片消息"（最多 20 张图）

## 一、打开素材视图

命令面板执行 **"打开微信素材管理"**（或点击左侧边栏的 WeWrite 素材图标）。

视图包含 3 个 Tab：

| Tab | 内容 |
|-----|------|
| 图片 | 公众号素材库中的图片 |
| 图文草稿 | 公众号草稿箱中的图文 |
| 图片草稿 | 公众号草稿箱中的图片消息 |

## 二、同步素材

- 打开视图（或切换账号）时会自动从微信同步素材
- 手机端支持 **下拉刷新**（拖动列表顶部即同步）

## 三、常用操作

| 操作 | 方法 |
|------|------|
| 删除 | 选择项目 → 删除选中（已发布文章引用的素材会被标记，防止误删） |
| 下载到 Vault | 右键/长按 → 下载，存为本地文件 |
| 复制 CDN 链接 | 右键/长按 → 复制 URL，可贴到任意 Markdown |
| 设为封面 | 右键/长按 → 设为封面（{分区}），直接填入当前推文封面 |
| 批量选择 | 切换多选 → 全选/取消全选 → 删除 |

> 素材按账号隔离：顶部切换公众号账号后显示该账号的素材。

## 四、创建图片消息（NewsPic）

纯图片 + 说明文字的推送场景（如摄影集、产品图、公告图）：

1. 在笔记编辑器 **右键 → 「作为微信公众号图片消息」**（或命令面板）
2. 在图片消息视图中：
   - **添加图片**：从系统/仓库选择，最多 20 张
   - **拖拽排序**：调整图片顺序
   - **填写说明**：每张图可配说明文字
3. 手机框滑动预览效果
4. 点击 **发布**，推送到微信草稿箱
5. 手机「公众号助手」App 确认发送

## 五、常用技巧

- **素材复用**：素材视图里复制的图片链接可直接贴进任何笔记，发布时会被识别处理。
- **防误删**：已发布文章引用的素材会自动标记，删除时会二次确认。
- **手机端**：素材视图长按操作；下拉同步；触控目标 ≥ 44px。

---

## 常见问题

| 问题 | 解决 |
|------|------|
| 素材列表为空 | 确认顶部账号正确且网络可用；下拉/重新打开视图触发同步 |
| 删除素材失败 | 微信 API 限制：已被文章引用的素材可能无法删除；先解除引用 |
| 图片消息超过 20 张 | 微信上限 20 张，请精简 |
| 找不到「图片消息」入口 | 对笔记右键 → 作为微信公众号图片消息；或命令面板搜索 NewsPic |
