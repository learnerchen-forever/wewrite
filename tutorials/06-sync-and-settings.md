# 教程 6：多端同步与设置

> 电脑写的稿子，手机接着改、接着发。WeWrite 内置 WebDAV 同步（实验性）与完整的设置导入/导出。

---

## 目标

- 用 WebDAV 在多设备间同步 Vault
- 处理同步冲突
- 导入/导出/迁移设置
- 了解调试日志与重置

## 一、WebDAV 多端同步（实验性）

> ⚠️ **实验性功能**：仍可能存在数据冲突或丢失风险。启用前请自行备份重要数据；不要与其它同步插件（Obsidian Sync、Remotely Save 等）同时启用。

### 1. 准备一个 WebDAV 服务

推荐**坚果云**（免费版可用）：

1. 注册坚果云，登录网页版 → 右上角头像 → **账户信息 → 安全选项**
2. 在「第三方应用管理」中**添加应用**，得到专用密码（不是登录密码）
3. 记下你的 WebDAV 地址：`https://dav.jianguoyun.com/dav/`

### 2. 在 WeWrite 中配置

设置 → WeWrite → **Vault 同步**：

| 项 | 填写 |
|----|------|
| 启用同步 | 打开 |
| WebDAV 地址 | `https://dav.jianguoyun.com/dav/` |
| 用户名 | 坚果云账号邮箱 |
| 密码 | 上面生成的**应用专用密码** |
| 远程目录 | 建议每台设备一致，如 `obsidian/` |
| 同步间隔（分钟） | 自动同步频率，默认 10 |

1. 点击 **测试连接** 验证
2. 阅读风险提示并确认
3. 点击 **开始同步**

### 3. 使用注意事项

- 首次同步会把本地文件上传到远程目录；**远程目录名在所有设备上必须一致**
- 避免多台设备**同时编辑同一个文件**（可能产生冲突）
- 免费坚果云有请求频率与流量限制；遇到配额耗尽时 WeWrite 会自动暂停，配额重置后自动恢复（优先同步 .md 笔记）
- 大文件（默认 >50MB）会被跳过，可在设置中调整上限

## 二、处理同步冲突

当同一文件在多台设备都被修改时会产生冲突：

1. 命令面板执行 **"WeWrite Sync: 解决冲突"**
2. 弹窗列出冲突文件，逐条选择：
   - **保留本地** / **保留远程** / **保留两者**
3. 也可"一次性全部解决"
4. 解决后执行一次同步应用结果

> 查看历史：命令面板 **"WeWrite Sync: 查看日志"** 可回滚到历史版本。

## 三、设置导入 / 导出

设置 → WeWrite → **导入 / 导出**：

- **导出设置**：所有设置（公众号账号、AI 账号、样式等）导出为 JSON 文件。⚠️ API Key 以明文导出，请妥善保管。
- **导入设置**：从 JSON 恢复。支持 v1.x 与 v2.x 格式；无效账号自动跳过。首次启动还会自动检测并一键迁移旧版 v1 设置。

> 跨 Vault / 换电脑迁移：新 Vault 装上 WeWrite → 导入导出的 JSON 即可。

## 四、账号管理速查

| 账号类型 | 配置位置 | 测试 |
|----------|----------|------|
| 微信公众号 | 设置 → 微信公众号账号 | 测试连接（验证 AppID/AppSecret） |
| AI 文本 | 设置 → 文本 AI 模型 | 测试连接（验证 Key/地址） |
| AI 文生图 | 设置 → 文生图 AI 模型 | 测试连接（验证 Key/端点） |

## 五、调试与重置

- **记录发布过程 / 记录渲染管线 / 记录 AI 调用**：开启后把结构化日志写入 `wewrite/debug/`，排查问题时开启并复现，然后查看日志
- **清除指纹**：重置图片上传指纹，强制全部重新上传（封面或图片上传出错时使用）
- **清除笔记配置**：清空每篇笔记的渲染/发布设置（样式、封面、账号、media_id）
- **重置 WeWrite**：删除指纹、笔记配置、缓存、调试日志，恢复干净状态（不影响你的笔记）

## 六、WeWrite 文件夹结构

默认 `wewrite/` 文件夹（可在设置中更改）：

```
wewrite/
├── themes/    # 自定义主题笔记
├── cache/     # AI 生成图、裁剪/转换缓存
└── debug/     # 调试日志（发布/渲染/AI 调用）
```

## 常见问题

| 问题 | 解决 |
|------|------|
| 同步提示流量配额耗尽 | 免费坚果云限制约 30 分钟 600 次请求；WeWrite 会自动暂停并在配额重置后恢复，无需操作 |
| 同步报错 `TrafficRateExhausted` | 同上，等待自动恢复；频繁出现建议升级专业版 |
| 换设备同步不到 | 确认所有设备远程目录名一致、都启用了同步 |
| 忘记 WebDAV 密码 | 坚果云 → 账户信息 → 安全选项 → 第三方应用管理，重新生成 |
