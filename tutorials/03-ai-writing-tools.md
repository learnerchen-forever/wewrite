# 教程 3：笔记编辑与 AI 辅助写作

> 插入图片、校对、同义词、翻译、生成图表/公式、文生图——全部在 Obsidian 里完成，无需切换应用。

---

## 目标

- 配置 AI 文本账号与文生图账号
- 在笔记里插入图片（从仓库 / 从系统相册）
- 使用校对、同义词、翻译
- 生成 Mermaid 图表与数学公式
- 生成文章摘要与配图

## 一、配置 AI 账号

### 1. 文本 AI 账号（校对/同义词/翻译/图表/公式/摘要）

设置 → WeWrite → **文本 AI 模型** → 添加文本 AI 提供商：

| 提供商 | Base URL 示例 | 说明 |
|--------|--------------|------|
| OpenAI Compatible | `https://api.openai.com/v1` | 兼容 OpenAI 格式的服务均可（DeepSeek、通义、Kimi 等） |
| OpenAI | `https://api.openai.com/v1` | 官方 |
| Anthropic | `https://api.anthropic.com` | Claude |
| Google Gemini | `https://generativelanguage.googleapis.com` | Gemini 系列 |
| Ollama (Local) | `http://localhost:11434` | 本地模型 |
| OpenRouter | `https://openrouter.ai/api/v1` | 聚合多家模型 |

填写：名称、提供商、Base URL、API Key、模型名（如 `gpt-4o`、`deepseek-chat`、`qwen2.5`）。点 **测试连接** 验证后 **设为启用**。

### 2. 文生图账号（配图/封面）

设置 → WeWrite → **文生图 AI 模型** → 添加：

| 提供商 | 说明 |
|--------|------|
| 阿里万相 Wan 2.6 | 阿里云百炼，原生同步端点，**需要业务空间 ID**；尺寸 `W*H`，自动适配总像素区间 |
| 阿里千问 Qwen-Image 3.0 | 阿里云百炼，chat.completions / 原生 multimodal 端点，**需要业务空间 ID**；尺寸 `W*H`（每边 512–2048、8 的倍数） |
| 字节 Seedream 5.0 | 火山方舟，OpenAI 兼容；尺寸自动适配（总像素 ≥2560×1440、宽高为 64 的倍数），也支持 `1K/1.5K/2K/3K/4K` 档位 |
| OpenAI (DALL·E) | 固定三档：`1024x1024` / `1792x1024` / `1024x1792` |

> **业务空间 ID（Workspace ID）**：阿里两个提供商必须填写，Base URL 会自动拼接专属域名（如 `{workspaceId}.cn-beijing.maas.aliyuncs.com`）。
> **尺寸自动适配**：输入自由格式即可（`1440*613`、`2K`、`1024x1024`…），插件会按所选模型的合法约束自动换算（如 Seedream 会把低像素横幅 `1440*613` 自动放大到 `2944x1280`），并在提示/日志中说明换算结果。

## 二、使用入口

所有笔记编辑与 AI 功能在四个入口里完全一致：

1. **命令面板**（Ctrl/Cmd+P）：`插入图片（从仓库选择）`、`插入图片（从系统选择）`、`Proofread Text (AI)`、`Find Synonyms (AI)`、`Translate Selection (AI)`、`Generate Mermaid Diagram (AI)`、`Generate Math Formula (AI)`、`Generate Image by AI`
2. **编辑器右键 → WeWrite** 二级菜单（悬停即展开）
3. **笔记右上角「⋮」菜单 → WeWrite**（与右键菜单内容一致）
4. **移动端编辑器工具栏**——上面这些命令都能添加进去（见本节末尾）

> 二级菜单分三组：**插入图片**（从仓库 / 从系统）→ **AI 文本工具**（校对 / 同义词 / 翻译）→ **AI 生成**（图片 / Mermaid / 公式）。

### 把命令放到移动端工具栏

手机上没有右键菜单，工具栏是最快的入口。安装后依次进入：

设置 → 移动端 → **管理工具栏选项** → 搜索 `WeWrite` 或 `插入图片` → 添加需要的命令。

每个命令都带专用图标（仓库图片、系统图片、校对、同义词……），不会显示成「?」。

## 三、插入图片

写笔记时插图的两种方式，与封面选图用的是同一套实现：

| 命令 | 适用场景 | 说明 |
|------|---------|------|
| **插入图片（从仓库选择）** | 图片已在仓库里 | 以**缩略图网格**列出全库图片，可按文件夹筛选、按文件名过滤；分页加载，图片再多也不会卡 |
| **插入图片（从系统选择）** | 图片在手机相册 / 电脑磁盘上 | 调用系统自己的选图器，手机上就是相册 |

要点：

- 从系统选的图会**先复制进仓库**，再以 `![[...]]` 插入光标处——写入位置遵循你 Obsidian 的「新附件的默认位置」设置，并在重名时自动加序号
- 手机相机直出的 HEIC 等 Obsidian 无法显示的格式，会在写入时自动转成 PNG
- 插入的链接格式（Wiki 链接 / Markdown 链接）跟随你的 Obsidian 设置
- 走系统选图器还有一个副作用：它是 Obsidian 沙箱内**唯一**能摸到手机相册的通道。直接在应用里浏览文件系统在鸿蒙（出境易 / 卓易通）等环境下往往什么也看不到

## 四、文本校对

1. 选中要校对的文本；**不选则校对整篇笔记**
2. 右键 → WeWrite → **文本校对**
3. 弹出审阅窗口：顶部是**修正清单**，中间是当前这条问题的上下文、原文与建议

| 区域 | 作用 |
|------|------|
| 修正清单 | 列出全部问题，类型用**颜色**区分：拼写/标点=红、语法=橙、用词=蓝紫。点击任一条即可跳转 |
| 上下文 | 显示问题前后的原句，命中处高亮——弹窗遮住笔记时也能看清 |
| 原文 / 建议 | 只把**改动的那几个字**标出来（原文划掉、建议标绿），一眼看到改了什么 |
| 建议 | **点击建议文字即可编辑**，改完再接受 |
| 接受修改 / 忽略 | 应用建议 / 跳过，自动跳到下一条 |
| 批量按钮 | 句数较多时出现：接受或忽略**同类剩余**、忽略剩余全部 |

> 键盘：`←`/`→` 切换，`Enter` 接受，`Shift+Enter` 在编辑建议时换行，`Esc` 关闭。审阅结束后会给出「已接受 N 处，忽略 M 处」的小结，并可用 `Ctrl/Cmd+Z` 逐步撤销。

长笔记按约 6000 字符一段分批提交（这样每段都在模型的有效上下文里，结果更准），加载提示会显示进度「正在校对 2 / 5…」。单次最多 8 段——超出时只校对已覆盖的部分并提示实际字数，避免误按一次就跑掉几十次调用。

> 代码块、行内代码、frontmatter、`[[wiki 链接]]`、`![[嵌入]]`、URL、`$公式$` 等 Markdown 结构**不会**被送进模型，也不会出现在修正清单里——校对的永远只是正文。

## 五、同义词

1. 选中一个词（或把光标放在词上）
2. 右键 → WeWrite → **查找同义词**
3. 弹出同义词列表

| 区域 | 作用 |
|------|------|
| 替换「…」 | 指明这次要替换的是哪个词 |
| 义项 | 模型从**所在句子**读出的意思，例如「（形容词）外观令人愉悦」——同一个词在不同句子里是两套同义词 |
| 列表 | 每条为「序号 · 词 · 用法说明」（语域、搭配侧重的区别） |
| 重新查找 | 不满意可原地重roll，不用关掉重来 |

> 键盘：`↑`/`↓` 移动，`1`–`9` 直接选中第 N 条，`Enter` 替换，`Esc` 取消。选中的词会替换掉原文。

> **中文取词**：中文没有词边界。没有选中文本时，光标所在的中文串若超过 4 个字，插件不会猜——会提示你先选中要查的词，避免把一整句当成「同义词」替换掉。英文单词没有这个问题。

## 六、翻译

1. 选中文本 → 右键 → WeWrite → **翻译**
2. 选择目标语言（简体中文 / English / 日本語 / 한국어 / Français / Deutsch / Español / Русский / Português / Italiano）——语言会记住，下次打开默认还是它（仅本次会话）
3. 自动翻译后，可 **替换选中内容** 或 **复制** 结果

三件事值得知道：

- **代码和链接不会被翻译**。围栏代码块、行内代码、`$公式$`、`[[wiki 链接]]`、链接地址、URL、`#标签`、`{{模板变量}}` 会先用占位符藏起来，翻完再原样缝回去——模型看不到它们，也就翻不掉。
- **结构损坏会先告诉你**。万一模型还是漏掉或重复了某一段，译文上方会出现橙色告警（并说明是哪一段），而不是默默把残缺的译文替换进笔记。
- **长文本自动分段翻译**，不会在中途被截断；若译文明显短于原文，也会给出「可能被截断或概括」的提醒。

译文框可以**直接编辑**，改完再替换；不满意可点 **重新翻译**。

## 七、生成 Mermaid 图表

1. 右键 → WeWrite → **生成 Mermaid 图表**（或命令面板）
2. 在描述框里说明想要什么图，例如：*"用户登录的时序图：输入账号密码、验证、进入首页"*
   - 若有选中文本，会作为上下文提供给 AI，描述框也会预填
3. **图表类型**可以指定（flowchart / sequenceDiagram / classDiagram / stateDiagram-v2 / erDiagram / gantt / pie / journey / timeline / mindmap / quadrantChart / xychart-beta / gitGraph）；不确定就保持「自动选择」，指定类型比让模型猜更稳
4. 点击 **生成** → 结果框上方给出**语法检查结论** → 编辑/调整 → **插入到光标位置**（自动包成 ` ```mermaid ` 代码块）
5. 不满意可 **重新生成**

| 结果框上方的结论 | 含义 |
|------|------|
| 语法检查通过——图表应当能正常渲染。 | 首行图型、引号、`subgraph`/`end` 配对、残留围栏都查过了 |
| 自动检查未通过：… | 列出具体问题与行号；**插入前请自行确认**（结论行只是本地体检，不是完整解析器） |

> 检查未通过时插件会**带着具体错误自动向模型重试一次**；只有在结果确实变好时才采用重试的版本。结果框可编辑，**复制/插入**取的都是框里的当前内容。

## 八、生成数学公式

1. 右键 → WeWrite → **生成数学公式**
2. 描述公式，例如：*"一元二次方程的求根公式"*
3. 选择**公式形式**：独立成行（块级 `$$…$$`）或 行内（`$…$`）；较长的多行公式即使选了行内也会留在块级
4. 生成后上方给出校验结论，**插入到光标位置** 即可在 Obsidian 中渲染

- 结论写「MathJax 已成功编译」时，是用 Obsidian 渲染公式的同一个引擎**真编译过**的；未通过时会给出 MathJax 的原始报错（如 `Missing close brace`），并自动带该报错重试一次。
- 生成结果**不会重复包裹**：模型已经带 `$$`/`$` 时原样使用，只有裸 LaTeX 才会被包起来。
- 描述无法转成公式时（模型往往会回一句道歉），插件会明确提示而不是把那句话当公式插进笔记。

> 生成由内置技能（Skill）引导：AI 会先理解你的描述，再产出 Obsidian 兼容的高质量 Mermaid/LaTeX，不会附带多余解释。技能里也写进了实际会踩的坑——Mermaid 的关键词不能做节点名、标签含 `()` 要加引号；LaTeX 用 `aligned`/`cases` 而不是裸 `align`、不用 Unicode 数学符号、不用 `\newcommand`。

## 九、生成图片与摘要

- **配图**：右键 → WeWrite → **生成图片**，输入描述与尺寸，生成的图片保存到 `wewrite/cache/` 并插入 `![[...]]` 到光标处
- **封面**：推文视图封面区 → ✨ 按钮，按封面比例生成（见 [教程 4](04-cover-and-images.md)）
- **摘要**：推文视图摘要行 → ✨ 按钮，AI 按微信规范生成 ≤120 字摘要

## 十、调试与隐私

- 设置 → 调试/日志 → **记录 AI 调用** 开启后，每次调用会写入 `wewrite/debug/ai-call-*.md`（含模型、提示词、响应），排查问题用
- API Key 加密存储；关闭记录后不会写入日志

## 常见问题

| 问题 | 解决 |
|------|------|
| 提示「未配置 AI 文本账号」 | 设置中配置并启用一个文本 AI 账号 |
| 提示「未配置 AI 图片生成账号」 | 设置中配置并启用一个文生图账号 |
| 校对结果明显错误 | 校对只做"纠错"；风格类建议可在审阅时忽略。长文本建议分段校对 |
| 生成的 Mermaid 在 Obsidian 不渲染 | 重新生成或微调描述；避免要求插件类图表类型 |
| 从系统选不到照片（华为鸿蒙等） | 确认走的是「插入图片（从系统选择）」——它调用系统相册；直接在应用内浏览文件系统在该环境下通常看不到任何文件 |
| 插入图片后笔记里是裂图 | 该格式 Obsidian 无法显示；从系统插入时插件已自动转 PNG，若仍异常请把图片放进仓库后用「从仓库选择」插入 |
| 移动端如何触发 | 把命令加到移动端工具栏（见「二、使用入口」），或长按编辑器呼出菜单、用命令面板执行 |
