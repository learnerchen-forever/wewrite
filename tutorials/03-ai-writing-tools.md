# 教程 3：AI 辅助写作

> 校对、同义词、翻译、生成图表/公式、文生图——全部在 Obsidian 里完成，无需切换应用。

---

## 目标

- 配置 AI 文本账号与文生图账号
- 使用校对、同义词、翻译
- 生成 Mermaid 图表与数学公式
- 生成文章摘要与配图

## 一、配置 AI 账号

### 1. 文本 AI 账号（校对/同义词/翻译/图表/公式/摘要）

设置 → WeWrite → **文本 AI 模型** → 添加文本 AI 提供商：

| 提供商 | Base URL 示例 | 说明 |
|--------|--------------|------|
| OpenAI Compatible | `https://api.openai.com/v1` | 兼容 OpenAI 格式的服务均可（DeepSeek、通义、Kimi 等） |
| OpenAI | `https://api.openai.com/v1` | 官方 |
| Anthropic | `https://api.anthropic.com` | Claude |
| Google Gemini | `https://generativelanguage.googleapis.com` | Gemini 系列 |
| Ollama (Local) | `http://localhost:11434` | 本地模型 |
| OpenRouter | `https://openrouter.ai/api/v1` | 聚合多家模型 |

填写：名称、提供商、Base URL、API Key、模型名（如 `gpt-4o`、`deepseek-chat`、`qwen2.5`）。点 **测试连接** 验证后 **设为启用**。

### 2. 文生图账号（配图/封面）

设置 → WeWrite → **文生图 AI 模型** → 添加：

| 提供商 | 说明 |
|--------|------|
| DashScope（通义万相） | 阿里云，异步任务，尺寸为固定集（如 `1024*1024`） |
| Seedream（豆包/火山方舟） | OpenAI 兼容，支持 `1024x1024`、`2K`、`4K` |
| OpenAI（DALL·E） | 支持 `1024x1024`、`1792x1024`、`1024x1792` |

## 二、使用入口

所有 AI 功能有两个入口，内容完全一致：

1. **命令面板**（Ctrl/Cmd+P）：`Proofread Text (AI)`、`Find Synonyms (AI)`、`Translate Selection (AI)`、`Generate Mermaid Diagram (AI)`、`Generate Math Formula (AI)`、`Generate Image by AI`
2. **编辑器右键 → WeWrite AI** 二级菜单（悬停即展开）

## 三、文本校对（Word 式审阅）

1. 选中要校对的文本（不选则校对整篇笔记，超过 6000 字自动截取前段并提示）
2. 右键 → WeWrite AI → **文本校对**
3. 弹出审阅窗口，逐个问题操作：

| 按钮 | 作用 |
|------|------|
| 接受修改 | 用建议替换错误文本，跳到下一个 |
| 忽略 | 跳过该问题，跳到下一个 |
| 上一个 / 下一个 | 切换问题（笔记会自动滚动并高亮对应错误） |

> 支持中英文的错别字、语法、标点、用词问题。键盘：`←`/`→` 切换，`Enter` 接受。

## 四、同义词

1. 选中一个词（或把光标放在词上）
2. 右键 → WeWrite AI → **查找同义词**
3. 弹出同义词列表：`↑`/`↓` 选择，`Enter` 确认——选中的词会被替换

## 五、翻译

1. 选中文本 → 右键 → WeWrite AI → **翻译**
2. 选择目标语言（简体中文 / English / 日本語 / 한국어 / Français / Deutsch / Español / Русский / Português / Italiano）
3. 自动翻译后，可 **替换选中内容** 或 **复制** 结果

## 六、生成 Mermaid 图表

1. 右键 → WeWrite AI → **生成 Mermaid 图表**（或命令面板）
2. 在描述框里说明想要什么图，例如：*"用户登录的时序图：输入账号密码、验证、进入首页"*
   - 若有选中文本，会作为上下文提供给 AI，描述框也会预填
3. 点击 **生成** → 预览结果 → **插入到光标位置**（自动包成 ` ```mermaid ` 代码块）
4. 不满意可 **重新生成**

## 七、生成数学公式

1. 右键 → WeWrite AI → **生成数学公式**
2. 描述公式，例如：*"一元二次方程的求根公式"*
3. 生成结果自动带 `$$ ... $$`，**插入到光标位置** 即可在 Obsidian 中渲染

> 生成由内置技能（Skill）引导：AI 会先理解你的描述，再产出 Obsidian 兼容的高质量 Mermaid/LaTeX，不会附带多余解释。

## 八、生成图片与摘要

- **配图**：右键 → WeWrite AI → **生成图片**，输入描述与尺寸，生成的图片保存到 `wewrite/cache/` 并插入 `![[...]]` 到光标处
- **封面**：推文视图封面区 → ✨ 按钮，按封面比例生成（见 [教程 4](04-cover-and-images.md)）
- **摘要**：推文视图摘要行 → ✨ 按钮，AI 按微信规范生成 ≤120 字摘要

## 九、调试与隐私

- 设置 → 调试/日志 → **记录 AI 调用** 开启后，每次调用会写入 `wewrite/debug/ai-call-*.md`（含模型、提示词、响应），排查问题用
- API Key 加密存储；关闭记录后不会写入日志

---

## 常见问题

| 问题 | 解决 |
|------|------|
| 提示「未配置 AI 文本账号」 | 设置中配置并启用一个文本 AI 账号 |
| 提示「未配置 AI 图片生成账号」 | 设置中配置并启用一个文生图账号 |
| 校对结果明显错误 | 校对只做"纠错"；风格类建议可在审阅时忽略。长文本建议分段校对 |
| 生成的 Mermaid 在 Obsidian 不渲染 | 重新生成或微调描述；避免要求插件类图表类型 |
| 移动端如何触发 | 长按编辑器呼出菜单，或在命令面板执行对应命令 |
